MacSlim 1.1.1-beta.2 将自动更新残留、缓存和日志整理作为主要用途。按目录结构识别常见更新器，保留账号、历史数据库与应用签名；旧内核仅供查看。

本次加入固定安装位置与每用户单实例保护。维护者发布流程使用同一份 GitHub DMG 完成本机安装，校验源码提交和完整应用文件树，并备份旧应用及测试副本。任务进行中不会强制退出替换。

支持目标为 macOS 13+，提供 arm64 / x86_64 Universal 构建。当前仍为 Ad-hoc 签名，未完成 Developer ID 与 Apple 公证；最低系统及干净环境首次安装尚需验收，因此先发布测试版本。未知缓存仍需人工检查，清理并非零副作用。

首次使用请将 MacSlim.app 拖入 /Applications，退出相关应用，先扫描并检查少量候选，默认移至废纸篓，确认正常后再决定是否清空。
