MacSlim 1.1.1-beta.3 修复更新残留的个人数据保护缺口及本机发布安装器的两处路径风险。建议使用 beta.2 的用户升级。

- 更新残留与缓存共用个人数据保护检查，执行清理时再次检查。仅通过 UpdatePackages、LarkShell/update、crx_cache 等通用目录名识别的候选默认不勾选。
- 新扫描记录包含分块计算的内容校验，能发现修改文件后恢复原大小与时间的情况。旧恢复记录仍可读取与恢复，继续使用原有校验。
- 安装器绑定已打开的目录与文件身份，拒绝不可信可写祖先目录；副本验证备份后移入私有目录再次核对，再删除。移除历史临时目录中仅按名称匹配可执行文件的清理逻辑。

支持目标为 macOS 13+，提供 arm64 / x86_64 Universal 构建。当前仍为 Ad-hoc 签名，未完成 Developer ID 与 Apple 公证；最低系统及干净环境首次安装尚需验收，因此保持测试版本。完整字节校验增加读取量；未知内容仍需人工检查，清理并非零副作用。

首次使用请将 MacSlim.app 拖入 /Applications，退出相关应用，先扫描并检查少量候选，默认移至废纸篓，确认正常后再决定是否清空。
