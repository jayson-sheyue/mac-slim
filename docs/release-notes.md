MacSlim 1.1.1-beta.4 新增英、日、中（`English` / `日本語` / `中文`）三语界面支持与三语 README 文档，并包含 1.1.1-beta.3 的全部个人数据保护与安装器安全校验修复。

- **三语界面与实时切换**：首次启动默认使用 `English`，可在主窗口顶部工具栏或“设置（Settings）”中随时切换 `English`、`日本語`、`中文` 并持久保存。切换语言会立即更新导航、状态栏、扫描规则识别依据与影响说明，不会清空当前扫描结果或重置任务。
- **配置兼容与回退**：从旧版本升级或缺少语言字段时平滑回退到 `English`；点击“恢复默认设置（Restore Defaults）”重置扫描阈值时保留用户已选语言。
- **数据与安装安全边界**：更新残留与缓存共用个人数据特征（Cookie、数据库、文档等）保护，执行前复核分块 SHA-256 指纹与关联进程运行状态；旧版内核仅供检查，不修改第三方应用包与签名。

支持目标为 macOS 13+，提供 arm64 / x86_64 Universal 构建。当前仍为 Ad-hoc 签名，未完成 Developer ID 与 Apple 公证；最低系统及干净环境首次安装尚需验收，因此保持预发布版本。
