MacSlim 1.1.1 正式版（内容同 1.1.1-beta.5）修复了部分账户目录与后台进程状态下闲置清理候选被误判为“正在使用”而无法勾选和删除的问题，并包含 1.1.1-beta.4 的英、日、中三语界面及此前全部安全校验机制。

- **精准进程关联与占用保护**：仅在受控清理目录内提取应用归属标识，按 Bundle ID 点边界或归一化应用名精确匹配，并过滤空 `bundleIdentifier` / `bundleURL` 的后台守护进程，避免系统账户目录名或通用缓存目录名误命中系统常驻服务；真正运行中的应用及其辅助进程继续保持严格跳过保护。
- **勾选与只读项交互改进**：支持点击条目主标题行或复选框幂等切换选择，工具栏新增按当前筛选范围生效的“全选（Select All / すべて選択）”；旧版应用框架（`inspectionOnly`）改为锁形标识与保护说明，清晰区分“可清理项”与“为保护应用签名而不可删除的仅检查项”。
- **数据与安装安全边界**：更新残留与缓存共用个人数据特征（Cookie、数据库、文档等）保护，执行前复核分块 SHA-256 指纹与关联进程运行状态；默认移至废纸篓并支持冲突保护恢复。

支持目标为 macOS 13+，提供 arm64 / x86_64 Universal 构建。当前仍为 Ad-hoc 签名，未完成 Developer ID 与 Apple 公证，首次打开可能出现 Gatekeeper 提示；最低系统、实体 Intel 及干净环境首次安装尚无真机验收记录。
